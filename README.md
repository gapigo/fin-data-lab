# fin-data-lab

Financial data platform: CVM, B3, PREVIC, SUSEP ingestion + modeling + API.

## Running

See [RUNNING.md](./RUNNING.md) — especially the **warning about stopping node processes** safely.

## Quick Reference

```bash
bun run api        # API on :8000
bun run frontend   # Frontend on :5173/:8081
bun run dev        # Both via concurrently
```
